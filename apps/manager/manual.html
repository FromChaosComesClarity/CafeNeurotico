1. Manifesto & Philosophy

Your Library. Manageable. Searchable. Portable.

I wanted an app that could organize and launch all my games — from Steam, GOG, Epic, Flatpak, Emulators, or whatever — in just one place.

I wanted it to be complete with all the features I’ve always wished I had in a Linux game manager: checking YouTube videos, HowLongToBeat, and ProtonDB right from inside the app, among other things.

I wanted it to be simple, beautiful and themeable.

And most importantly, I wanted it to be completely PORTABLE and BACKUPABLE.

The Local-Only Philosophy

CNGM is built with a strict Offline-First, Local-Only philosophy for your media. Once you fetch artwork, covers, logos, or download a trailer, it is saved securely into your local GameManagerConfig folder.

This means your library will never suffer from “link rot” or broken web images if a storefront changes its API. It also means you can pack up the entire folder, put it on a thumb drive, and take your flawlessly curated library to another PC entirely.

The Launch Command

The crucial feature. Inside the Edit Details screen, there is a field where you can put a command to launch any game. Anything goes — if you can run it on Linux, you can run it from here.

If you imported your games from Steam, or from GOG and Epic through GRINDER, the launch commands are filled in automatically, even if the game is not installed. Clicking PLAY will prompt you to install if needed.

2. The Suite at a Glance

Cafe Neurotico is one AppImage with three faces. There is nothing to install and nothing extra to download — every part of the suite ships inside the single file.

The Three Faces

  • The Manager — the desktop face. Import, organize, scrape, edit and launch your library with a mouse and keyboard. This is where you are right now.
  • CREMA — the fullscreen, gamepad-first face for the living room. Same library, same artwork, same playlists — zero configuration, always in sync. Launch it with the coffee-cup button in the titlebar or run the AppImage with --crema.
  • GRINDER — the GOG & Epic engine. It signs in to your accounts, downloads games, configures Proton and launches them. It works silently inside the other two faces; its own window (run with grinder) is there for deep per-game tuning.

EmuLatte, the ROM library manager, is a separate app — but the suite detects EmuLatte.AppImage sitting in the same folder and integrates it into your app menu and sidebar.

Your ROM library stays in EmuLatte; the suite does not swallow it. You decide which games cross over by exporting them to Cafe Neurotico from inside EmuLatte — only those appear here, as ordinary library entries filed under Emulation, which play, scrape and join playlists like any other game. Keep the whole collection in EmuLatte and promote just the ones you want on the shelf.

All three faces read and write the same library database. Mark a favourite on the couch and it is a favourite on the desktop. Install a game from CREMA and the Manager knows immediately.

3. Quick Start

The Welcome to the System screen appears on every launch (until you tell it not to) and walks you through the whole setup in three steps — each with live buttons, so you never have to leave the screen:

  1. Import your games. Steam: paste your free API key and SteamID64, hit Fetch Steam Library. GOG & Epic: press Sign in right here — a store login window opens, you log in, and it closes itself. After that, new purchases import automatically every time you press Refresh Library. Flatpak, PICO-8 and itch.io games are picked up automatically when you open their filters.
  2. Fetch artwork & metadata. One button scrapes covers, hero art, logos, descriptions, HowLongToBeat and ProtonDB data for everything you just imported.
  3. Add to your app menu. One click registers Cafe Neurotico and CREMA (and EmuLatte, if detected) in GNOME, KDE or any desktop launcher, with proper icons.

Bring it back anytime: the Welcome screen lives in Menu → System. Nothing in it is exclusive — every action also exists in Connect and the Control Panel.

Your Files

On first launch the app creates a GameManagerConfig folder next to the AppImage:

  • games.db — your entire library database: games, metadata, playlists, settings
  • images/ — covers, hero art, logos, icons, screenshots
  • trailers/ — locally downloaded MP4 trailers

GRINDER keeps its own data (store logins, install records) in ~/.config/grinder/ — per-machine on purpose, since installed games differ between computers.

4. The Manager — Importing Your Games

Open Connect (the chain-link icon in the side rail, or Control Panel → Connections). All data stays local; no cloud account is ever required to use the app.

Steam

  • Get a free API key at steamcommunity.com/dev/apikey and your SteamID64 from your profile URL.
  • Your Steam Game Details privacy must be set to Public for the API to list your games.
  • The import includes played free-to-play titles (tagged with a green FREE pill) and even Steam’s “unvetted” small releases that the API normally hides.
  • Free games and demos you never launched are invisible to Steam’s API entirely. The Manager works around it by also reading your local Steam install folders, so anything actually installed on this machine gets imported whether Steam admits to owning it or not.
  • Playtime (total and last two weeks) is captured on every sync.

GOG & Epic

  • Sign in without leaving the Manager. The Welcome screen and Connect both have GOG and Epic sign-in buttons: press one, the store’s own login page opens in a window, and it closes itself the moment you’re authenticated. You never have to open GRINDER for this — it’s tucked away behind Advanced now.
  • From then on, Refresh Library pulls your full owned list from both stores automatically — buy a game, hit refresh, it appears (as “not installed”, ready to install in one click).
  • DLC and soundtracks are filtered out automatically; a GOG/Epic copy of a game you also own on Steam merges into one entry with a launcher picker.

Games That Leave

Refresh Library doesn’t only add. If you refunded a GOG or Epic game, or uninstalled a Steam demo you never owned, it now disappears from your library too instead of lingering as a dead entry forever. Games you own on more than one store lose only the store you parted with — the entry itself stays, with the remaining launcher.

Nothing you curated is at risk: only genuinely un-owned store entries are removed. Custom games, emulator entries and anything you added by hand are never touched by a refresh.

Flatpak, PICO-8, itch.io

  • Flatpak: clicking the Flatpak filter scans installed apps and even generates cover art from their icons.
  • PICO-8: point the app at your PICO-8 binary (Control Panel) and your cart folder is scanned; carts get their label art as covers, plus Splore and the BBS browser.
  • itch.io: sync your owned library through the itch integration in Connect.

Emulation (EmuLatte)

ROMs are not imported by scanning. You curate them in EmuLatte and export the ones you want from inside EmuLatte; they land here as normal library entries under Emulation. Nothing crosses over on its own, so your 3,000-ROM set never floods the shelf — only the games you chose.

Anything Else

Add Custom Game (Control Panel → Library) creates an entry for any game or app. Give it a launch command — if it runs on Linux, it runs from here. Store-less entries are filed under Others automatically.

5. The Manager — The Library

The library has two views — Gallery (cover grid) and List (a sortable table) — plus a persistent icon rail on the left.

The Search Row

Both views share the same search row at the top:

  • Search — instant, searches titles as you type.
  • Category dropdown — jump to any store or filter (Steam, GOG, Epic, Flatpak, PICO-8, itch.io, Installed, Favourites, Want to Play…). Stays in sync with the rail buttons.
  • Sort dropdown — A — Z, Last Played, Favourites First, Want to Play First, Recently Added, Scraped First. Your choice is remembered across restarts. Any sort other than A—Z hides the “Recent Games” strip so the whole grid reads in your chosen order.
  • Playlist dropdown — jump into any playlist, the Recently Imported feed, or create a new playlist on the spot.
  • Games count — live count of what you’re looking at.

The Side Rail

Icons for All Games, Favourites, Want to Play, store filters, playlists, plus Add Game, Connect, the Control Panel and Refresh Library. Filters combine: stores are OR’d, qualifiers (Installed, Favs, Want) are AND’d.

Gallery Cards

Each cover carries its information quietly: an install dot (green = installed, orange = not), store badges, a FREE pill on free-to-play games, hover flags for Favourite / Want / Playlist, and an inline Play or Install button. One click opens the gamepage.

Ken Burns hero: the gallery header slowly pans across your library’s screenshots. If you’re on older hardware, turn it off in Control Panel → Appearance.

6. The Manager — The Gamepage

The gamepage opens as a floating panel over your library — the grid stays blurred behind it, and clicking outside (or the Back button) drops you exactly where you left off, scroll position included.

What’s On It

  • Hero art with the game’s logo, store icons and the store/category logo in the corner.
  • Action row: Favourite, Want to Play, Add to Playlist (and Remove, when it’s in one), Hide (eye icon — removes the game from every view; manage hidden games in the Control Panel), Open in Steam, Uninstall, SPLORE (PICO-8), Watch Trailer, and Edit Details.
  • Browse Local Files (folder icon) — opens the game’s install folder in your file manager. It works out where the game actually lives for Steam, GOG, Epic and even emulator entries (following the ROM path out of the launch command), and simply doesn’t appear for games that aren’t installed.
  • DLC panel — installed GOG games list their owned DLC, with badges for what’s already on disk and a one-press Install all DLCs.
  • Save Manager — finds, backs up and restores your save games. See section 20.
  • Floating Play/Install button, always visible at the bottom right.
  • Metadata column: achievements ring (press to see the full list), release year, developer, genre, HowLongToBeat, Metacritic, ProtonDB tier, similar games (clickable links when you own them).
  • Description — the short summary plus the full Steam page write-up, and a screenshots strip with a slideshow.
  • Click the box art to see it full-size in a lightbox.

Edit Details

Opens directly on top of the gamepage (same panel, seamless). Every field is yours to change: title, store, launch command, artwork, screenshots, description, franchise, flags. Custom art you set by hand is protected from being overwritten by re-scrapes.

7. The Manager — Installs & the Download Manager

How Installing Works

  • Steam games install through the Steam client (steam://install) — Steam opens and takes over.
  • GOG & Epic games install in-process through the built-in GRINDER engine: pick a folder, see the download size and your free disk space up front, and watch live progress. No external window.
  • Linux or Windows build? For the GOG games that ship both, the install dialog lets you choose — native Linux, or the Windows build run through Proton. Your choice is remembered per game.
  • Cancel really cancels: the whole download process tree is stopped, not just the parent, so a cancelled install doesn’t sit there half-finished.
  • Uninstall (gamepage action row) removes the game files and its Wine prefix.

The Download Manager

Start more than one install and they queue — each begins automatically when the previous one finishes. Manage the queue from:

  • The downloads icon in the titlebar (with a live count badge) — works even when nothing is downloading.
  • The progress bar that appears at the top during any download — click it to open the manager; click outside to return to it.

Inside: the active download with live percentage and a Cancel button, the waiting queue (remove anything), and a history of completed installs. Click any game’s name to jump to its gamepage.

Phone notifications: with KDE Connect (or GSConnect) paired, the “Game installed” and “Now Playing” notifications — cover art included — appear on your phone automatically. Toggle in Control Panel → Behavior.

8. The Manager — Scraping & Artwork

Scraping fills your library with covers, hero images, logos, icons, screenshots, descriptions, genres, release years, HowLongToBeat times, Metacritic scores and ProtonDB tiers. Everything downloads to your local images/ folder — no link rot, ever.

  • Auto-Fetch (Edit Details) — one game, one click, everything found.
  • Batch Fetch (Control Panel → Library, or the Welcome screen) — sweeps every game that’s missing data. After a Refresh Library, you’re offered a scrape of just the new arrivals.
  • SteamGridDB (free key at steamgriddb.com) — browse fan-made grids, heroes and logos and pick your favourite per game.
  • IGDB (free Twitch dev credentials) — richer metadata and the fallback for non-Steam games.
  • Trailers — search YouTube from inside the app and download a local MP4; it plays on the gamepage and in CREMA.

Your art is safe: re-scraping never overwrites artwork you set manually.

10. Playlists, Hidden Games & Free-to-Play

Playlists

  • Create from the rail, the search-row dropdown, or any game’s + Playlist button — that picker has a “+ New playlist…” box built in, so you can invent a playlist and drop the game into it in one go, even if you had none to begin with. Order is yours; games can live in many playlists.
  • Recently Imported is an automatic feed of your newest arrivals (size configurable in Behavior; newest always on top).
  • Playlists appear in CREMA as first-class categories, marked with ≡. Changes sync both ways instantly.

Hidden Games

Hide anything via the gamepage’s eye button — it vanishes from every view in both faces, instantly. Unhide from Control Panel → Behavior → Hidden Games (or CREMA’s menu), each game individually.

Free-to-Play

Steam free-to-play titles you’ve played are imported and tagged with a green FREE pill (gallery, list and gamepage). Click any pill — or use Control Panel → Behavior — to show or hide them all, or hide just that one game.

12. CREMA — Overview & Setup

CREMA is the suite’s living-room face: fullscreen, gamepad-first, TV-sized type. It reads the same library as the Manager — nothing to configure, nothing to copy.

Launch it from the Manager’s titlebar coffee-cup button, the app menu entry (“CREMA (Fullscreen)”), or CafeNeurotico.AppImage --crema. It can also autostart on login for HTPC builds (Control Panel → System).

First Run

A two-step setup asks how you want your start screen (Carousel or Grid of categories) and how you like to browse (List with a live media panel, or a cover Gallery). Both are changeable anytime in the menu. After that you land on the Home screen.

Waking up: while a game runs, CREMA sleeps behind it. Press START + SELECT (configurable) to bring it back.

19. GRINDER — the GOG & Epic Engine

GRINDER does the heavy lifting for DRM-free stores: authentication, downloads, Proton/Wine setup, redistributables, launching and uninstalling. Most of the time you never see it — the Manager and CREMA drive it silently.

You no longer sign in here. GOG and Epic logins happen directly in the Manager’s Welcome and Connect screens. GRINDER’s window is for tuning, not setup.

When to Open Its Window

  • Per-game tuning: Proton version, Wine prefix, winetricks, environment variables, esync/fsync, DXVK-NVAPI, launch arguments, custom executables.
  • “▶ Log” — Play with Log. Next to every installed game’s Launch button. It starts the game exactly as normal but streams everything the game and Wine print into a live window — the first thing to reach for when a title refuses to start. Copy the log with one button. Closing the window doesn’t disturb the game.
  • “⬇ Size” sort — order the library by how much disk each install actually occupies. This is what Manage Storage opens.
  • DLC: list, install and reset the DLC of your installed GOG games.
  • Its own download manager, install log, repair/verify tools and a library view of everything it manages.

GOG DLC is installed as a set. GOG’s downloader cannot safely add one DLC on its own — asking it to will delete the base game. So the DLC panel always reinstalls the game together with all the DLC you own, which is slower but never destroys anything.

GRINDER’s data lives in ~/.config/grinder/ — logins and install records are per-machine, which is why a fresh copy of the suite still knows your GOG library on the same computer.

20. Save Games — Backup & Restore

Installed GOG and Epic games get a Save Manager panel on their gamepage. GOG and Epic have no save-sync worth the name on Linux, so the suite gives you the honest version: find the saves, zip them up, put them back.

This is a desktop-face feature — it lives on the Manager’s gamepage, not in CREMA.

Finding Your Saves

Save files hide in genuinely awful places — somewhere inside a Wine prefix, under a numeric account folder, or right next to the game. The Save Manager tries three things in order:

  1. The store’s own answer. GOG ships a save path inside each game’s manifest and Epic publishes a cloud-save folder; when either exists, that is used, account ID and all.
  2. The Wine prefix. Failing that, it searches the game’s prefix in the usual places (Documents, AppData, Saved Games), skipping the empty scaffolding Wine creates for every prefix.
  3. The install folder — where older games have always kept them.

If all three come up empty, use Locate saves… and point at the folder yourself; your choice is remembered. And “no saves yet” is a perfectly normal answer for a game you haven’t played.

Backing Up

Tick the folders you want and press Back Up. You get a dated ZIP with a manifest inside it recording where every file came from. Because the manifest travels with the archive, a backup made on one PC restores correctly on another, even with a different username, a different install path or a different account folder.

Restoring

  • Pick a backup and confirm — the panel tells you exactly what it’s about to overwrite.
  • A snapshot of the current saves is taken first, automatically, and filed alongside your other backups. If a restore turns out to be the wrong move, the state you just replaced is still sitting there.
  • Restore is a true replace, so a save the game deleted stays deleted — with a guard that refuses to wipe a folder shared by several games.
  • Delete any backup you no longer want from the same list.

Backups are ordinary ZIP files — copy them to a drive, a NAS or a cloud folder yourself. Nothing is uploaded anywhere on your behalf. LEARN MORE in the panel explains the whole flow in-app.

22. Tips & Troubleshooting

  • Steam import returns nothing: your Steam profile’s Game Details must be Public. Double-check the SteamID64 (17 digits).
  • A newly bought GOG/Epic game isn’t showing: hit Refresh Library — it pulls the fresh owned list from both stores. If it still doesn’t appear, open Connect and check the GOG/Epic cards still say you’re signed in; store tokens do expire, and signing in again takes a few seconds.
  • A game won’t start and says nothing useful: open GRINDER, find it, and press ▶ Log instead of Launch. The verbose window shows what Wine or the game actually complained about — usually a missing dependency you can install from the same screen’s winetricks.
  • A game vanished after Refresh Library: that’s the removal check — the store no longer reports you as owning it (refunded, or a demo you uninstalled). Re-buy or reinstall it and the next refresh brings it back.
  • A game shows Install instead of Play (or vice-versa): Refresh Library reconciles install state with GRINDER and Steam.
  • Missing artwork after import: run Batch Fetch; for stubborn games open Edit Details and scrape with a corrected title, or pick art manually via SteamGridDB.
  • GPU usage while idle: animations pause automatically when the window loses focus; the Ken Burns effect can also be disabled outright in Appearance.
  • CREMA feels out of sync: it re-reads the shared database on focus and refresh — if you edited a lot on the desktop, back out to the Start screen and re-enter.
  • Moved the folder? Re-run Add to Application Menu so the launcher entries point to the new location.
